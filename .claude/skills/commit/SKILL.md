# /commit

Prepare commits using conventional commit messages.

Rules:
- Format commit messages as `<type>(<scope>): <description>` when a scope is helpful.
- Keep commits thematic; separate unrelated work.
- Keep test-only changes in their own commit when practical.
- Do not add co-author trailers.
- Append a short note to `CHANGELOG_STAGING.md` after each commit session.
