Rules form the stems and point marks form the heads. Upward and downward
triangles distinguish positive and negative values; diamonds mark values near
zero. A separate rule marks the zero baseline.

:::{admonition} Data use and provenance
:class: note

NumPy creates regularly spaced positions; GenomeSpy calculates the sine wave.
No source dataset is required.
