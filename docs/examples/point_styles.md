Compare shapes, colors, and sizes across columns. Moving down the rows changes
outline thickness and rotation. Legends are hidden so the grid remains the focus.

:::{admonition} Data use and provenance
:class: note

NumPy creates the positions; GenomeSpy arranges them into a grid. The smallest points
have zero size, following the upstream example.

Adapted from the [official GenomeSpy example](https://genomespy.app/playground/?spec=/docs/example-specs/docs/grammar/mark/point/plenty-of-points.json).
:::
