Zoom in to explore the dense point cloud. Points grow as you zoom, while
colors distinguish the sample groups. Drag to pan around the embedding.

:::{admonition} Data use and provenance
:class: note

This adapts GenomeSpy's [t-SNE example](https://genomespy.app/playground/?spec=../examples/tSNE/tsne.json)
and loads its hosted Parquet file directly. The upstream specification calls
this an unsuccessful t-SNE attempt and does not identify the original study
or data-specific license. Use it as an interaction demonstration, not evidence
of meaningful biological clusters. Loading requires an internet connection;
the dataset is not bundled with the Python package.
:::
