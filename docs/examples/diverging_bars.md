Every bar starts at zero. Red bars extend below the baseline and blue bars
extend above it. A threshold color scale switches colors at zero.

:::{admonition} Data use and provenance
:class: note

NumPy creates 60 positions. GenomeSpy calculates the wave-shaped values in
the browser. No source dataset is required.

Adapted from the [official GenomeSpy example](https://genomespy.app/playground/?spec=/docs/example-specs/docs/grammar/mark/rect/bars.json).
:::
