Drag the selected range along the colorbar to move the highlighted bands.
Scroll over the plot to zoom. Drag the plot to pan. Points grow as you zoom in.

GenomeSpy generates all one million points in the browser. The Python code
uses expression helpers to describe the surface and its colors.

:::{admonition} Data use and provenance
:class: note

Synthetic points use the standard [torus parameterization](https://reference.wolfram.com/language/ref/Torus.html), tilted into a flat view. A wave around the surface creates the winding bands.

Adapted from the [official GenomeSpy example](https://genomespy.app/playground/?spec=/docs/example-specs/core/interaction/legend-brush-torus.json).
:::
