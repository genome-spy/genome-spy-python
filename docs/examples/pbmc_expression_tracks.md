Each track shows a marker gene's **log-transformed counts** across individual
cells. Each bar represents one cell, colored by cell type.

Use the mouse wheel to zoom and drag to pan. All tracks move together.
The vertical scales differ between genes, so check the ticks before comparing
heights.

Use the [heatmap](pbmc_cell_heatmap.md) to inspect exact cell values.

:::{admonition} Data use and provenance
:class: note

12 markers from 2,638 cells in Scanpy's processed
[10x Genomics PBMC3k dataset](https://www.10xgenomics.com/datasets/3-k-pbm-cs-from-a-healthy-donor-1-standard-1-1-0)
(CC BY 4.0), retaining its log-transformed counts and cell-type labels.
:::
